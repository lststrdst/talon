# Talon

Прочитай инструкции проекта и выбери режим по результату, который запросил пользователь.

Для новой или смешанной кодовой базы используй соседний навык `stack`, если требуется определить языки, инструменты сборки и тесты. Ограничь выбор затронутым компонентом и его фактическими файлами.

Для сложной фичи, совместимости API, передачи работы и проверки ветки используй соседний навык `delivery`.

Для локального повторения CI, проверки на временной базе или очереди, web E2E и отчёта JUnit используй соседний навык `checks`.

Для AD DS, GPO, DNS, SCIM и Яндекса используй соседний навык `directory`. Выбирай документацию по сервису и редакции.

- **Разобрать или спланировать.** Найди точку входа, путь по исходникам, действующий контракт и ближайший пример. Для плана дай выполнимые шаги и критерии готовности без правок. Используй [работу с кодом](references/feature-work.md).
- **Реализовать или изменить.** Проведи один рабочий сценарий через реальную точку входа. Сохрани совместимость данных и вызывающего кода, проверь затронутые права, повтор и отказ. Используй [работу с кодом](references/feature-work.md). Для PowerShell, GPO, служб и установщиков открой [руководство PowerShell](references/powershell.md).
- **Проверить или починить.** Для проверки оставь код и тесты в режиме чтения. Для исправления воспроизведи сбой, внеси целевую правку и подтверди результат. Используй существующий runner и [проверки по типу дефекта](references/failure-testing.md). Windows-поведение подтверждай в подходящем контексте Windows.

Для **Python** открой [сценарий скриптов и проверок](references/python-scripts.md). Для **серверов** выбери [Windows Server](references/windows-server.md) или [Linux](references/linux-server.md) и [доступ по SSH](references/remote-ssh.md). Для диагностики сохраняй режим чтения. Для скрипта или изменения зафиксируй начальное состояние, фактический прогон и наблюдаемый результат.

Для небольшой задачи достаточно текущего агента и целевой проверки. При существенном изменении или параллельных независимых проверках используй [роли команды](references/agent-roles.md). Для сложной развилки используй настроенную более сильную модель на одном конкретном этапе, если рантайм и пользователь разрешают такой выбор.

В задачах с конкретным проектом [память Talon](references/project-memory.md) включена по умолчанию. Найди релевантные записи в `.agents/talon/learned.md` или `.talon/learned.md` до исследования. Перед итоговым ответом сохрани нестандартную проверку, которую удалось подтвердить и которая нужна повторно. Используй `.talon/learned.md`, когда `.agents/` защищён. Соблюдай режим плана или аудита и явное отключение памяти.

При работе с Hermes Agent, OpenCode, OpenClaw, Pi или DeepSeek Harness выбери отдельный навык по [маршрутизации рантаймов](references/harness-routing.md). При конкретном пробеле используй применимый навык, уже доступный в выбранном рантайме. Подбор новых навыков ограничь текущей задачей.

В конце назови результат и фактически выполненные проверки. Если есть полезное продолжение, предложи один следующий шаг и его ожидаемый эффект.
