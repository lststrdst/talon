## Talon в этом проекте

Для содержательных задач по коду, фичам, PowerShell, Python, серверам и QA используй установленный навык `talon` из `.agents/skills/`. Для простой правки используй только нужные шаги. Учитывай настройки доверия и доступа текущего рантайма.

Включена память Talon в `.agents/talon/learned.md`. Читай только записи по текущей задаче. После подтверждённого результата сохраняй проверенный способ решения, если он пригодится повторно. Для плана и аудита используй память только для чтения, если её обновление отдельно не запрошено.
