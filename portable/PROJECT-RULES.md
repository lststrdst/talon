## Talon в этом проекте

Для содержательных задач по коду, фичам, PowerShell, Python, серверам и QA используй установленный навык `talon` из `.agents/skills/`. Для простой правки используй только нужные шаги. Учитывай настройки доверия и доступа текущего рантайма.

Память Talon действует по умолчанию. Ищи записи по задаче в `.agents/talon/learned.md` и `.talon/learned.md`. После подтверждённого результата сохраняй проверенный способ решения, если он пригодится повторно. Если `.agents/` защищён, пиши в `.talon/learned.md`. Для плана и аудита используй память только для чтения, если её обновление отдельно не запрошено. По запросу пользователя отключай память для проекта или задачи.
