# Поиск UI/UX Pro Max

Все пути в командах начинаются от абсолютной папки загруженного навыка в переменной `talon_design_dir`. Сам поиск работает на стандартной библиотеке Python с локальной папкой `data/`.

## Выбери данные по задаче

| Задача | Ключ поиска | Файл для чтения без Python |
| --- | --- | --- |
| Продукт и визуальное направление | `--domain product`, `--domain style` | `data/products.csv`, `data/styles.csv` |
| Цвет и типографика | `--domain color`, `--domain typography` | `data/colors.csv`, `data/typography.csv` |
| Структура лендинга | `--domain landing` | `data/landing.csv` |
| Доступность и взаимодействие | `--domain ux` | `data/ux-guidelines.csv` |
| Графики, иконки и анимация | `--domain chart`, `--domain icons`, `--domain gsap` | `data/charts.csv`, `data/icons.csv`, `data/motion.csv` |
| Реализация в конкретном стеке | `--stack` с фактическим стеком | `data/stacks/` |

`--json` возвращает полные поля. Без него длинный текст в человекочитаемой выдаче сокращается. `--design-system --json` возвращает совокупное направление, включая паттерн, стиль, палитру, типографику и ограничения. Проверь соответствие результатов задаче перед их применением.

## Сохрани согласованное направление

Сначала прочитай существующие токены, документацию и `design-system/` проекта. Когда сохранение полезно для запрошенной реализации, укажи абсолютный корень проекта в `talon_project_dir` и подходящее имя проекта.

```sh
python3 "$talon_design_dir/scripts/search.py" "beauty spa wellness" --design-system --persist -p "Wellness" --output-dir "$talon_project_dir"
```

Замени пример продуктом и именем своего проекта. Пример создаёт `design-system/wellness/MASTER.md`. `--page booking` добавляет `pages/booking.md` с локальными отклонениями. `--tokens dtcg` экспортирует токены JSON, `--tokens css` также создаёт CSS. Обычный запуск сохраняет существующий MASTER.md. `--force` применяй только в рамках запрошенной перезаписи.

`--preview` генерирует HTML. Без `--persist` укажи отдельную папку артефакта через `--output-dir`. HTML может содержать ссылки Google Fonts, которые браузер загрузит при открытии. Для изолированной среды используй шрифты и ассеты, доступные в проекте.

При отсутствии Python прочитай ограниченный набор подходящих строк CSV, нужный раздел `references/quick-reference.md` и действующую дизайн-систему. Потребность в новом интерпретаторе или пакете согласуй отдельно, если существующая авторизация задачи её не охватывает.
