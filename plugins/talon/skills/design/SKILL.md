# Talon · Дизайн

Доведи задачу до запрошенного результата — решения по интерфейсу, макета, работающего кода или аудита. Основа навыка — локальная база и поисковое ядро UI/UX Pro Max. Прочитай существующие правила проекта, найди его компоненты, токены, состояния и дизайн-систему. Сохраняй выбранное пользователем визуальное направление.

## Выбери действие

- Для нового экрана определи пользователя, основное действие, содержимое и состояния. Используй действующую дизайн-систему. Если её ещё нет или пользователь просит новое направление, подбери согласованные layout, цвет, типографику и плотность через `--design-system`.
- Для локальной правки найди затронутый компонент и выполни целевой запрос по UX, стилю или стеку. Ограничь изменение нужным сценарием.
- Для аудита изучи текущий интерфейс и проверь наблюдаемое поведение. Укажи подтверждённые проблемы, место и способ воспроизведения. Изменения кода и макета определяются запросом пользователя.

## Найди рекомендации

Определи абсолютную папку именно этого загруженного `SKILL.md` и запиши её в переменную `talon_design_dir`. Вызывай её `scripts/search.py` по этому пути из рабочей папки проекта. Установленный плагин и веб-архив могут находиться в разных местах. Сохраняй рядом с `scripts/` папку `data/`.

Для выполнения поиска нужен доступный Python 3. Проверь его наличие. Выбери установленный `python3` или `python`, на Windows также подходит `py -3`. Если Python или выполнение команд недоступны, прочитай подходящие строки CSV и справочники ниже, укажи использованный способ и продолжи задачу.

Формулируй краткие английские ключевые слова по продукту и проблеме, чтобы сопоставить их с локальными данными. Для новой визуальной системы и целевой проверки доступны такие команды.

```sh
python3 "$talon_design_dir/scripts/search.py" "beauty spa wellness" --design-system --json
python3 "$talon_design_dir/scripts/search.py" "keyboard focus modal" --domain ux --json
python3 "$talon_design_dir/scripts/search.py" "responsive form validation" --stack react --json
```

Определи стек по проекту или явному выбору пользователя и замени `react` фактическим значением. Запрос `--design-system` собирает общее направление. Рекомендации реализации для конкретного стека получай отдельным вызовом `--stack`. Доступные домены и стеки показывает `--help`.

Сверь домен, верхние результаты и применимость к платформе. При пустой или нерелевантной выдаче уточни запрос один раз. Генератор может предложить маркетинговую структуру для рабочего dashboard. Структуру приложения выводи из пользовательского сценария и выбирай только подходящие рекомендации. Данные нужно сопоставлять с проектом и актуальными API. Для правил взаимодействия и доступности читай нужный раздел [общего справочника](references/quick-reference.md). Для нативных мобильных интерфейсов дополнительно используй [правила mobile UI](references/pro-rules.md). Параметры поиска, сохранения и локальные файлы описаны в [справочнике поиска](references/search.md).

## Реализуй и проверь

Выбери артефакт из запроса и контекста. Для кода используй существующие компоненты, токены, иконки и проверки проекта. Для работы в Figma применяй соответствующий доступный навык Figma и подтверждай результат в файле. Если запрошенный инструмент недоступен, подготовь применимый результат в доступной среде и явно укажи, что получилось создать и проверить.

Проверь затронутый сценарий в целевой среде. Для UI это могут быть узкий и широкий viewport, длинный текст, клавиатура и фокус, контраст, загрузка, пустое состояние и ошибка. Выбирай проверки по изменению. Используй доступный браузер, снимок экрана или нативный инструмент. Для существенного изменения передай сценарии и итоговую версию в `$talon:qa`.

В результате назови сделанные изменения или обнаруженные проблемы, проверки и оставшиеся ограничения. Предложи один следующий шаг, если он даёт конкретную пользу проекту.
