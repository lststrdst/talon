# Talon · Навыки под проект

Подключай навык ради конкретного действия в текущей задаче. Начни с описаний уже доступных навыков и известных файлов проекта. При подходящем установленном навыке прочитай его инструкцию и продолжи работу. Для простого изменения вроде текста, цвета или известной локальной правки этого достаточно.

## Подбери с небольшим расходом контекста

При конкретном пробеле сформулируй, какое действие навык должен улучшить. Один короткий поиск по этому пробелу возвращает до трёх кандидатов. Выбери один с понятной пользой. Повторное использование результата в чате и подготовленного кэша предпочтительно повторному поиску. За одну обычную задачу подключай до двух новых навыков. Дополнительный поиск нужен при смене стека, нового существенного этапа или явного запроса пользователя.

Определи абсолютную папку этого загруженного `SKILL.md` и запиши её в `talon_autoskills_dir`. Найди установленный Node.js 22.6+ и запиши его абсолютный путь в `talon_node`. Проверь PATH перед запуском. На Mac с локальными инструментами Talon запасной путь — `~/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node`. В смешанной рабочей папке укажи корень нужного проекта.

Короткий помощник использует установленный пакет `~/.local/share/talon/autoskills/0.4.1/package`. Для другой установки укажи её абсолютный корень через `--package`. Команда возвращает только метаданные кандидатов, без полного каталога и инструкций.

```sh
"$talon_node" "$talon_autoskills_dir/scripts/assist.mjs" suggest --project "$talon_project_dir" --query "vitest mocking"
```

Замени пример двумя–четырьмя английскими ключевыми словами по задаче. Сверь имя, источник и назначение кандидата с уже доступными навыками. Читай только выбранный `SKILL.md` и необходимые ему разделы. Длинные справочники загружай по месту применения. Навык-заглушку с перенаправлением на другой пакет пропусти, если нужное руководство в нём отсутствует.

## Подключи и примени

Когда пользователь разрешил автоматическое подключение подходящих навыков, подготовь один выбранный набор в приватном кэше задачи. Это разрешение может быть задано ранее в чате или инструкциях пользователя. При отсутствии такого разрешения предложи конкретный навык с ожидаемой пользой и продолжай доступную работу.

```sh
"$talon_node" "$talon_autoskills_dir/scripts/assist.mjs" prepare --skill "имя-из-выдачи"
```

Помощник скачивает ровно этот набор через API закреплённого autoskills, проверяет хеши и повторно использует готовый кэш. Прочитай инструкцию по возвращённому абсолютному пути `skillPath`, оцени её применимость и выполни нужный этап основной задачи. Подготовка файлов даёт возможность прочитать навык в текущем чате. Регистрация в списке навыков проекта является отдельным действием.

Обычный кэш находится в `~/.cache/talon/task-skills`. Если права среды разрешают запись только во временную папку, передай её отдельный приватный каталог через `--cache`. В режиме аудита используй именно такой разрешённый каталог артефактов.

Для автоматической подготовки помощник ограничивает набор 80 файлами и основной `SKILL.md` 24 КиБ. Кандидат с предупреждением проверки, большим набором или недоступной загрузкой переводится в краткую рекомендацию. Зафиксируй причину и продолжи основную задачу доступными средствами. При разрешении сетевой загрузки не исполняй команды из скачанных инструкций автоматически. Применяй их в рамках текущего запроса, режима аудита, прав среды и инструкций проекта. Перед применением проверь, что инструкция относится к нужному инструменту и версии.

В результате достаточно одной строки о подключённом навыке и его вкладе. Для явного запроса на обзор навыков покажи более подробный список. Для постоянной установки в проект или подготовки самого CLI прочитай [отдельный сценарий](references/project-install.md).

Если Node, пакет или выполнение команд недоступны, подбери один навык по известному стеку и доступным источникам, предложи его с причиной и продолжи работу. Обозначь, получена ли рекомендация из CLI или по файлам проекта.
