# Talon · Навыки под проект

Определи стек и подбери навыки, которые дополняют уже доступные. Запрос на подбор выполняй через просмотр рекомендаций. Установку выполняй, когда пользователь просит установить или подключить навыки. Сохраняй его выбор и уже разрешённый объём работы.

## Проверь проект и CLI

Прочитай инструкции проекта, манифесты и существующие навыки. В смешанной папке выбери корень нужного проекта. Сопоставь рекомендации с задачей и доступными навыками Talon, ECC и проекта. Проверь одноимённые каталоги и симлинки в `.agents/skills` и каталогах используемых агентов, прежде чем разрешать запись.

Используй autoskills **0.4.1**, Node.js **22.6+**. Сначала проверь `~/.local/share/talon/bin/autoskills`, затем `autoskills` в PATH. Для найденной команды установи версию по её пакету, а поддержанные параметры — по `--help`. Если подходящей команды нет, используй закреплённый пакет через npx. Npx скачивает исполняемый пакет и может заполнить кэш npm даже при `--dry-run`.

Установи для каждого запуска переменную `AUTOSKILLS_REGISTRY_BASE_URL` в точное значение ниже. Это закрепляет источник файлов навыков на опубликованной ревизии. CLI сверяет файлы и полный набор с SHA-256 из манифеста пакета.

```sh
AUTOSKILLS_REGISTRY_BASE_URL='https://raw.githubusercontent.com/midudev/autoskills/b4489cbdc36ba8c9de8f4dd844bab0b6b559579f/packages/autoskills/skills-registry' \
  npx --yes --package=autoskills@0.4.1 autoskills --dry-run -a universal
```

Выполняй команду из выбранного корня проекта. Для проверенного локального CLI замени часть `npx … autoskills` его путём, сохрани переменную и аргументы. `-a universal` пишет навыки в `.agents/skills`, откуда их читает Codex. Отдельного сопоставления `-a codex` в этой версии нет. CLI поддерживает обычный запуск и подкоманду `ui`; команды `install <имя>` нет.

## Подбери и установи

1. Выполни `--dry-run`. Объясни, какие рекомендации относятся к задаче, какие уже покрыты установленными навыками и какие стоит пропустить. Для установки проверь `securityCheck` выбранных записей в `skills-registry/index.json` пакета и инструкции самих навыков. Предварительный просмотр 0.4.1 показывает список без подробностей этих проверок. Оценка upstream не заменяет проверку источника и фактических действий навыка.
2. Для разрешённой установки убери `--dry-run`. В TTY выбери нужные имена и проверь выбор перед запуском. **Без TTY CLI выбирает весь найденный список даже без `--yes`.** Флаг `--yes` также выбирает весь список. Используй такой запуск только когда весь список входит в запрос.
3. CLI может перезаписать одноимённый навык, обновляет `skills-lock.json` и кэш `~/.cache/autoskills/skills-registry`. После установки он удаляет старый блок `<!-- autoskills:start --> … <!-- autoskills:end -->` из `CLAUDE.md`, а опустевший файл может удалить. Флага отключения этой очистки нет. Если есть такой блок, конфликтующие навыки или нужен частичный выбор без TTY, выполни установку в локальном временном снимке нужного проекта с сохранёнными сигналами стека. Продвигай в исходный проект только выбранные новые каталоги `.agents/skills/<имя>` и соответствующие записи lock-файла. Сохрани остальные записи lock-файла. Инструкции проекта из снимка не переноси. Для замены существующего навыка используй разрешённое пользователем обновление и покажи его diff.
4. Проверь наличие `SKILL.md` и всех файлов выбранных наборов, итоговый diff и сохранность существующих навыков и инструкций проекта. Укажи реально установленные имена, источник, версию CLI и проверку доступности в новом чате. Установка файлов сама по себе не подтверждает обновление текущего списка навыков.

`autoskills ui --no-open` запускает локальный сервер на `127.0.0.1`. Его интерфейс умеет устанавливать и удалять навыки, в том числе найденные в домашней папке. Используй его только когда пользователь просит этот интерфейс, и завершай сервер после работы. Обычный подбор обходится предварительным просмотром.

## Если CLI недоступен

В веб-чате или среде без Node изучи доступные файлы проекта и предложи небольшой список навыков с причиной выбора и официальными ссылками. Если файлов недостаточно, уточни стек. Для установки выдай команду предварительного просмотра для терминала пользователя с закреплённой версией выше. Укажи, что получилось определить по файлам и какой результат CLI ещё предстоит получить.
