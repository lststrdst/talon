# Постоянная установка навыков

Используй этот сценарий для запроса на сохранение навыков в проекте или настройку CLI. Для подбора во время обычной задачи достаточно `suggest` и `prepare` из основного навыка.

## Подготовь CLI

Нужны Node.js 22.6+ и autoskills 0.4.1. Найди `~/.local/share/talon/bin/autoskills` или CLI в PATH. Для установки закреплённого пакета через npx доступен такой предварительный просмотр.

```sh
AUTOSKILLS_REGISTRY_BASE_URL='https://raw.githubusercontent.com/midudev/autoskills/b4489cbdc36ba8c9de8f4dd844bab0b6b559579f/packages/autoskills/skills-registry' \
  npx --yes --package=autoskills@0.4.1 autoskills --dry-run -a universal
```

Npx заполняет кэш npm и скачивает исполняемый пакет. Для помощника Talon нужен абсолютный путь к корню пакета с `package.json`, `dist/` и `skills-registry/index.json`. Передай его через `--package`.

## Установи выбранное

Прочитай инструкции проекта, существующие `.agents/skills` и `skills-lock.json`. Сопоставь выбранный навык с реально доступными Talon, ECC и проектными навыками. Сохраняй существующие файлы и симлинки. Для запроса обновить навык покажи его diff.

Для точечной установки используй проверенный набор из приватного кэша `prepare`. Перенеси только выбранную папку в `.agents/skills/<имя>`. В `skills-lock.json` сохрани остальные записи и добавь для выбранного имени `source` из результата, `sourceType` со значением `autoskills-registry` и `computedHash` из `bundleHash`. При конкурирующем изменении повторно прочитай lock-файл перед записью. Для всей группы по явному запросу CLI поддерживает интерактивный выбор в TTY.

У CLI 0.4.1 есть особенности, важные для прямого запуска.

- Без TTY обычный запуск выбирает весь найденный список, даже без `--yes`. Флаг `--yes` тоже выбирает весь список.
- После установки CLI удаляет старый блок `<!-- autoskills:start --> … <!-- autoskills:end -->` из `CLAUDE.md`. Если файл опустеет, он может быть удалён. Помощник `prepare` использует API установки одного навыка и обходится без этого этапа CLI.
- `-a universal` размещает навыки в `.agents/skills`. Отдельного сопоставления `-a codex` и команды `install <имя>` в CLI этой версии нет.
- `autoskills ui --no-open` поднимает локальный интерфейс управления навыками. Используй его по запросу и останови сервер после работы.

Проверь `SKILL.md`, полный набор файлов, итоговый diff и сохранность инструкций проекта. Доступность в селекторе подтверждай обновлённым списком навыков. Пока он не обновился, прочитай установленный `SKILL.md` по известному пути и применяй его к текущей задаче.
