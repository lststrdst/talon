# Talon · Каталоги, политики и Яндекс

Определи, к какому сервису относится задача, версию установленного компонента, среду и ожидаемый результат. Если запрос касается нескольких систем, проследи одну проверяемую цепочку от исходного источника до наблюдаемого поведения.

| Задача | Руководство |
| --- | --- |
| AD DS, LDAP, DNS домена, GPO, репликация и RSoP | [AD, GPO и DNS](references/ad-gpo-dns.md) |
| Протокол SCIM, сопоставление идентификаторов, синхронизация и отключение | [SCIM](references/scim.md) |
| YandexADSCIM, Яндекс 360, Directory API, SSO, почта, Яндекс Трекер или Yandex Cloud | [Документация Яндекса](references/yandex.md) |

Используй встроенный справочник для выбора действий. Перед изменением проверь актуальную документацию по нужной редакции, версии и сервису. Для YandexADSCIM в первую очередь выясни, какая редакция работает, и какой источник объектов, конфигурация и целевая организация относятся к задаче.

Начни с чтения описания и состояния согласованного окружения. Для изменений определи ограниченный пилот, исходное состояние и способ отката. Проверяй эффект отдельно от факта записи конфигурации. Данные каталога, токены и сырые журналы оставляй в среде проекта. Для проверки контейнера, браузера или API на тестовом стенде используй [Воспроизводимые проверки](../checks/SKILL.md), если они нужны для задачи.
