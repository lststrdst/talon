# Диагностика ошибок в Sentry

Открой сценарий, когда нужно проверить ошибки конкретного проекта после релиза или во время диагностики. Сверь организацию, проект, среду и интервал с задачей. Используй подключённый Sentry с доступом к нужному проекту. Для CLI попроси передать токен через штатное хранилище среды процесса с разрешением `event:read` для Issues API. В запросах и отчётах используй идентификаторы и метаданные ошибки. [Sentry Authentication](https://docs.sentry.io/api/auth/), [List an Organization's Issues](https://docs.sentry.io/api/events/list-an-organizations-issues/).

[query_issues.py](../assets/sentry/query_issues.py) использует стандартную библиотеку Python 3 и выполняет один `GET` по явно указанному HTTPS-адресу организации. Для облака укажи подтверждённый адрес региона Sentry, для своей установки укажи её HTTPS-адрес. Если для частной установки используется собственный центр сертификации, передай его PEM через `--ca-file`. Скрипт возвращает выбранные поля issue и `next_cursor`, если на следующей странице есть результаты. Он сохраняет область запроса при повторе с `--cursor` и отклоняет перенаправления. [Sentry API Reference](https://docs.sentry.io/api/), [Sentry Pagination](https://docs.sentry.io/api/pagination/).

```sh
python3 query_issues.py --origin "$sentry_origin" --organization "$sentry_org" \
  --project "$sentry_project" --environment "$sentry_environment" --period 2h \
  --query 'is:unresolved' --limit 20
```

Уточни поиск через `--query`, если в гипотезе есть релиз или тип ошибки. `--query ''` включает все статусы. Для сравнения до и после распространения релиза подбери окна и критерий в отчёте Sentry, который учитывает события за интервал. Одна страница Issues API показывает совпавшие группы в рамках выбранных фильтров. Пустой список означает отсутствие совпадений запроса. HTTP `401`, `403` или `429` означают соответственно проблему авторизации, доступа или ограничения частоты. [Параметры Issues API](https://docs.sentry.io/api/events/list-an-organizations-issues/), [Ограничение запросов](https://docs.sentry.io/api/ratelimits/).

Фикстура HTTPS подтвердила отправку одного `GET` с фильтрами и bearer-токеном, выдачу сокращённого результата с курсором, отклонение перенаправления и отказ при issue из другого проекта. Сверку со своим Sentry выполняй при наличии доступной организации и разрешений.
