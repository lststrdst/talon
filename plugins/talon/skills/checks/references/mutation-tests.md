# Заметит ли тест ошибку в условии

Используй мутационное тестирование, если обычный набор проходит и нужно проверить, заметит ли он ошибку в конкретном расчёте, фильтре или граничном условии. Выбери одну функцию с понятным контрактом и запусти относящиеся к ней тесты на исходной версии. Продолжай после успешного базового прогона с выполненными тестами.

Для Python найди в проекте конфигурацию mutmut и рабочую команду pytest. В конфигурации mutmut укажи проверяемый код через `source_paths` и выбранные тесты через `pytest_add_cli_args_test_selection`. Шаблон в `mutmut run` ограничивает набор мутаций. Временная копия компонента позволяет изолировать результаты и кэш. Например, если модуль называется `limits`, а функция — `fits_batch`, используй следующие команды в окружении с mutmut 3.8.1.

```sh
python -m pytest -q tests/test_limits.py
mutmut run 'limits.x_fits_batch*'
mutmut results --all true
```

Возьми идентификатор выжившей замены из вывода и посмотри её через `mutmut show <id>`. Проверь, есть ли допустимый вход, на котором изменится наблюдаемое поведение. Например, при включительной границе замена `count <= limit` на `count < limit` сохранит результаты для 4 и 6 при лимите 5. Тест `assert fits_batch(5, 5)` различит реализации. После добавления проверки повтори базовый и мутационный прогоны в свежей копии с тем же набором замен. [Руководство mutmut](https://mutmut.readthedocs.io/en/latest/)

Для проекта с настроенным StrykerJS используй его команду из package.json или локальный `stryker run` с конфигурацией проекта. Ограничь область мутации выбранным модулем и сохрани отчёт с исходным выражением, заменой и результатом запуска. [Команда StrykerJS](https://stryker-mutator.io/docs/stryker-js/usage/)

В отчёте укажи, какая замена пережила исходные тесты и какая проверка её поймала. Эквивалентная замена может сохранять контракт на всех допустимых входах. Отдельно учитывай выжившие замены, непокрытый код и ошибки среды. Процент обнаруженных мутаций описывает чувствительность набора к выбранным заменам. [Статусы мутаций](https://stryker-mutator.io/docs/mutation-testing-elements/mutant-states-and-metrics/)
