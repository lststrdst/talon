# Локальный граф ComfyUI

Выбирай ComfyUI, если в задаче нужен существующий граф, конкретная модель, управляемая серия или локальное выполнение. Начни с доступной сборки, модели и графа проекта. Для новой задачи на готовой установке предпочитай небольшой граф со штатными узлами. [ComfyUI](https://github.com/Comfy-Org/ComfyUI)

1. Определи назначение входных изображений, модель, размеры, ожидаемый файл и доступное оборудование. Открой локальный интерфейс и проверь список узлов графа до запуска. Для графа из внешнего источника сначала проверь сторонние узлы, ссылки на модели и узлы с сетевыми вызовами. Пользовательские узлы выполняют код, и их установка определяется отдельным запросом. Для локального результата используй граф, способный выполнить операцию локально. [Требования к сторонним узлам](https://docs.comfy.org/installation/install_custom_node)
2. Запусти один пробный кадр на существующем экземпляре. Для повторяемого прогона сохрани файл workflow, версию ComfyUI, модели и значимые параметры, включая seed. Интерфейсный workflow и API-представление графа сохраняй в нужном для последующей работы виде. Для вызовов действующего self-hosted API сверяй маршруты с версией сервера. [Маршруты self-hosted API](https://docs.comfy.org/development/comfyui-server/comms_routes)
3. Дождись завершения, открой полученный файл и сверяй результат с заданием. Если операция зависит от отсутствующей модели, незнакомого узла или недоступного сервера, укажи точную зависимость и используй разрешённый альтернативный путь. При повторе сохраняй исходник и меняй один значимый параметр за раз.
