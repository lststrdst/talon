# Talon · Изображения

Доведи работу до запрошенного изображения, правки или набора файлов для проекта. Для кадра в интерфейсе начни с места использования, пропорций на целевых экранах и элементов, которые должны остаться в кадре. Для работы в конкретном проекте проверь [память Talon](../go/references/project-memory.md) по визуальным требованиям и способам экспорта.

## Выбери инструмент

| Запрос | Действие |
| --- | --- |
| Новый кадр, фон, иллюстрация или правка содержимого | Используй встроенный ImageGen и доступный навык `imagegen`. Для правки укажи исходник, область изменения и детали, которые нужно сохранить. |
| Кадрирование, размер, сжатие, формат или конкретные пиксели | Используй штатный инструмент проекта. При его отсутствии примени доступные Sharp или ImageMagick по [справочнику экспорта](references/export.md). |
| Повторяемый локальный граф, модель или уже выбранный пользователем генератор | Используй доступный выбранный инструмент. Для ComfyUI открой [сценарий локального графа](references/comfyui.md). При отсутствии встроенного ImageGen назови доступный вариант и условия его использования. Для CLI OpenAI соблюдай порядок подтверждения навыка `imagegen`. |
| Редактируемый макет, компоненты, векторная иконка или диаграмма | Для интерфейса открой [Дизайн](../design/SKILL.md) и продолжи в исходном формате проекта. Для структурной схемы используй подходящий инструмент схем с редактируемым исходником. |

## Создай или отредактируй изображение

1. Укажи назначение, главный объект, композицию, освещение и необходимые ограничения. Для предметной фотографии задай материалы, ракурс и окружение. Если изображение должно представлять конкретный товар, сверяй геометрию, цвета, этикетку и комплектацию с предоставленным референсом. Для текста поверх изображения оставь свободную область, предусмотренную макетом.
2. Различай исходник для правки и референсы стиля или композиции. Для точного текста передай формулировку дословно и проверь её по готовому изображению. Если правку можно сделать штатным редактируемым слоем, используй его для точного позиционирования, локализации или подстановки брендинга.
3. Открой результат. Проверь предмет, перспективу, материалы, ореолы у контура, лишние детали и сохранность заданных свойств. Для прозрачного фона проверь альфа-канал и края на светлой и тёмной подложке. Если результат расходится с заданием, исправь конкретное отклонение и снова открой файл.

## Подготовь результат к использованию

Для проектного файла используй согласованный путь и сохрани версии, нужные для целевого использования. Замена существующего файла определяется запросом. Для адаптивных вариантов и проверки вёрстки открой [справочник экспорта](references/export.md). Открой настоящий экран, компонент или конечный документ в целевой среде, если задача включает интеграцию. В результате укажи пути, фактические размеры и форматы, выполненные проверки и использованный инструмент.
