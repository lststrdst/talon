# Навыки агентских рантаймов

Выбирай один навык по названию целевого рантайма или нужной возможности уже доступного рантайма. Для сравнения нескольких открывай только относящиеся к вопросу навыки. В обычной задаче по коду или QA без такой зависимости этот этап пропускай.

| Навык | Когда открыть |
| --- | --- |
| [Hermes Agent](../../harness-hermes/SKILL.md) | `harness-hermes` для проектных навыков, профиля, контекста, памяти и делегирования Hermes. |
| [OpenCode](../../harness-opencode/SKILL.md) | `harness-opencode` для планирования и исполнения, навыков проекта, разрешений и ревью с подагентом. |
| [OpenClaw](../../harness-openclaw/SKILL.md) | `harness-openclaw` для рабочих папок, разрешённых инструментов, сессий и подагентов. |
| [Pi Coding Agent](../../harness-pi/SKILL.md) | `harness-pi` для терминальной работы с репозиторием, расширений и MCP. |
| [DeepSeek Harness](../../harness-deepseek/SKILL.md) | `harness-deepseek` для проектных навыков, профилей, нативных инструментов и делегирования. |

В Codex используй соответствующий `$talon:harness-*` из списка навыков. В переносимом наборе используй тот же идентификатор без префикса через список навыков выбранного рантайма. Когда нужный навык не виден, сверяй его наличие и доступ по правилам хоста. Не считай разметку файлов или доступность бинарника подтверждением активной сессии и настроенных инструментов.

Различай **куда пользователь хочет подключить Talon** и **где сейчас выполняется задача**. Для настройки изучи выбранный целевой рантайм. Для исполнения сверяй фактически доступные инструменты, рабочую папку и права текущего сеанса. Если нужного инструмента нет, используй доступное средство либо дай конкретное условие для проверки. Само чтение навыка не запускает внешний рантайм, не меняет провайдера и не включает MCP, gateway или расширения.
