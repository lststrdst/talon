# Выбор модели в Talon

GPT-6.2 Sol с уровнем Ultra ведёт обычную работу, когда эта настройка выбрана в основном чате. Учитывай выбранные пользователем модель и уровень для текущей задачи. Сложность оцени по уже известным фактам, без отдельного вызова для классификации.

Когда для обычного поручения нужен отдельный агент, при запуске явно укажи `gpt-6.2-sol` и `ultra`, сохраняя нужную роль. Если инструмент допускает выбор модели только без истории, передай короткое самодостаточное поручение. Если инструмент отдаёт выбор модели Codex, используй его настроенные значения по умолчанию для подагентов.

Подключи GPT-6.2 Astra для одного конкретного этапа, когда более глубокий разбор может изменить решение. Например, когда остаются конкурирующие варианты архитектуры, причина воспроизводимого сбоя проходит через несколько компонентов или изменение затрагивает совместимость данных и откат. Для локальной правки с понятным критерием, штатной реализации и обычного прогона тестов продолжай на основной модели. Если Astra уже ведёт чат или нужный этап, используй её текущую работу.

При запуске подагента укажи `gpt-6.2-astra` с уровнем `xhigh` (Extra High). Если инструмент требует отдельного контекста для выбора модели, передай цель, пути, факты проверки, границы записи и ожидаемый результат в поручении. В Codex с установленными профилями можно вызвать `talon-astra`. Назначай ему сложный этап анализа, реализации или ревью. По возможности используй его вместо одного уже необходимого специалиста, сохраняя отдельную приёмку, когда она нужна. Дождись результата, проверь существенные выводы и продолжи основную задачу.

Повторное поручение сохраняет модель уже созданного агента. Для нового поручения повторно используй агента с подходящими моделью и уровнем. Если они отличаются или неизвестны, запусти нового с нужными настройками и передай ему краткий результат предыдущей работы. Сверяй параметры запуска перед тем, как указывать модель в отчёте.

Явный выбор модели или ограничения на делегирование имеют приоритет. Если выбранная модель или инструмент делегирования недоступны, продолжай на доступной модели. Укажи замену кратко, когда она влияет на ожидаемый результат.
