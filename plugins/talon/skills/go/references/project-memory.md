# Память проекта

Храни рабочие знания в `.agents/talon/learned.md` корня проекта. Память действует, когда проект подключил её через `AGENTS.md`, файл уже создан для проекта или пользователь попросил запоминать рабочие решения. Для аудита и плана используй записи только для чтения, если пользователь отдельно не попросил их обновить.

Перед исследованием найди заголовки по имени компонента, команды или симптома. Открой только совпавшие записи. Сверь путь, версию и условия с текущим кодом. Используй заметку как отправную точку для проверки, поскольку код, среда и политика проекта могли измениться.

После успешной проверки добавь запись, если следующий агент сможет применить её к повторяющемуся сценарию. Запиши условия, рабочий шаг и способ подтвердить исход. Если решение заменяет прежнее, обнови совпавшую запись по существу. Перечитай файл непосредственно перед правкой, чтобы сохранить правки других сеансов. Пропускай очевидные команды проекта и одноразовые случаи.

```markdown
## Компонент и сценарий
- Условие: версия, источник запуска или симптом.
- Проверено: относительный путь и команда либо шаг, который сработал.
- Результат: наблюдение, которое подтверждает решение, и граница проверки.
```

Очищай команды и данные. Для повторного прогона достаточно формы команды и синтетического примера без секретов, имён пользователей, внутренних адресов и сырых журналов. Сохраняй собственное подтверждённое наблюдение, избегай копирования внешних инструкций. Общие правила, разрешения и настройки подагентов меняются по инструкциям проекта. Перед переносом записи в другой проект проверь новые условия и подтверди результат заново.
