# Talon

Talon — плагин для Codex, который ведёт задачу от идеи до работающего изменения, проверяет результат и помогает подготовить запуск. Для сложного бага Talon может поручить диагностику, тестирование и приёмку разным подагентам. Итог показывает, что воспроизвелось, какие проверки прошли и где ещё нужны данные или стенд.

Начальный релиз — **1.4.0**. Пакет находится в [`plugins/talon`](plugins/talon).

## Установка

Добавьте каталог с GitHub и установите Talon через Codex CLI.

```sh
codex plugin marketplace add https://github.com/lststrdst/talon.git
codex plugin add talon@talon-marketplace
```

Откройте новый чат Codex в рабочем проекте и отправьте, например, такой запрос.

```text
$talon:go Сделай экспорт отчёта в CSV и проверь пустые данные, кириллицу и права доступа.
```

[Документация OpenAI по каталогам плагинов](https://developers.openai.com/plugins/build/plugins#add-a-marketplace-from-the-cli)

## Пять режимов

| Вызов | Что делает | Пример задачи |
| --- | --- | --- |
| `$talon:go` | Выбирает нужный режим и связывает этапы по порядку. | Проверь готовность сборки и подготовь анонс. |
| `$talon:build` | Уточняет контракт, разбирает архитектуру и доводит согласованную реализацию до рабочего сценария. | Добавь экспорт и проверь его на данных с кириллицей. |
| `$talon:qa` | Воспроизводит баги, проводит аудит или исправляет регрессию, проверяет готовность релиза. | Воспроизведи сбой сохранения, исправь причину и проверь результат. |
| `$talon:launch` | Выбирает аудиторию и канал, готовит черновик анонса и измеримый пилот. | Подготовь двухнедельный пилот и приглашение для первой команды. |
| `$talon:pentest` | Готовит область пентеста и по явному поручению запускает Strix на разрешённой цели. | Составь план проверки авторизации для изолированного стенда. |

## Именованные QA-агенты

Опциональные TOML-профили задают шесть ролей. Это диагност, браузерный тестер, API-тестер, Windows-тестер, разработчик исправления и независимый ревьюер. Talon выбирает роли по задаче. При отсутствии именованного профиля он может использовать доступного подагента с соответствующим поручением.

Чтобы подключить роли для своих проектов, клонируйте репозиторий и скопируйте профили. Команды пропускают существующие одноимённые файлы.

```sh
git clone https://github.com/lststrdst/talon.git
cd talon
talon_profiles=~/.codex/agents
mkdir -p "$talon_profiles"
for profile in plugins/talon/agent-profiles/*.toml; do
  target="$talon_profiles/${profile##*/}"
  if [ ! -e "$target" ] && [ ! -L "$target" ]; then
    cp -n "$profile" "$target"
  fi
done
```

После копирования откройте новый чат. Для подключения ролей только в одном проекте используйте каталог `.codex/agents/` в его корне. [Документация OpenAI по подагентам](https://learn.chatgpt.com/docs/agent-configuration/subagents#custom-agents)

## Дополнительные инструменты

Эти инструменты устанавливаются отдельно. Talon использует их при наличии и по задаче.

- **Graphify** помогает составить карту крупной кодовой базы и найти связи между компонентами перед правкой. [Документация Graphify](https://docs.graphify.com/open-source/configuration/cli)
- **Agent Reach** дополняет веб-поиск публичными обсуждениями и другими материалами для исследования аудитории. Доступ зависит от площадки и маршрута. [Репозиторий Agent Reach](https://github.com/Panniantong/Agent-Reach)
- **Strix** выполняет активные проверки безопасности веб-приложений и API. Для запуска нужны настроенные Docker и модель, явное поручение и точная область, которую пользователь вправе тестировать. [Быстрый старт Strix](https://docs.strix.ai/quickstart)
